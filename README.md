# Projeto: Jóias Personalizadas

Deploy do Site: https://joiaspersonalizadas.netlify.app/

Site Feito para finalizar a materia de (Interação Humano Computador), da faculdade Uninove no curso de Analise e Desenvolvimento de Sistemas

Descrição rápida
- Site estático de apresentação de uma pequena empresa de jóias personalizadas.
- Arquivo principal: [index.html](index.html).

Tecnologias e bibliotecas usadas
- HTML/CSS: estrutura do site e estilo principal em [index.html](index.html) e [css/estilo.css](css/estilo.css).
- Bootstrap (grid e componentes): [frameworks/bootstrap/css/bootstrap.css](frameworks/bootstrap/css/bootstrap.css) e [frameworks/bootstrap/js/bootstrap.js]. Fontes do Bootstrap: [frameworks/bootstrap/fonts/](frameworks/bootstrap/fonts/).
- jQuery: [frameworks/jquery/jquery-3.1.1.js](frameworks/jquery/jquery-3.1.1.js).
- Font Awesome (ícones): [frameworks/font-awesome/css/font-awesome.css](frameworks/font-awesome/css/font-awesome.css) e [frameworks/font-awesome/css/font-awesome.min.css](frameworks/font-awesome/css/font-awesome.min.css). Arquivos adicionais: [frameworks/font-awesome/fonts/](frameworks/font-awesome/fonts/), [frameworks/font-awesome/less/](frameworks/font-awesome/less/), [frameworks/font-awesome/scss/](frameworks/font-awesome/scss/).
- Magnific Popup (galeria modal): CSS e JS em [frameworks/magnific-popup/magnific-popup.css](frameworks/magnific-popup/magnific-popup.css) e [frameworks/magnific-popup/jquery.magnific-popup.js](frameworks/magnific-popup/jquery.magnific-popup.js).
- ScrollReveal (animações de entrada): [frameworks/scrollreveal/scrollreveal.js](frameworks/scrollreveal/scrollreveal.js).
- Google Fonts (tipografia): chamadas externas em [index.html](index.html).
- JavaScript customizado: [js/scripts.js](js/scripts.js).
- Imagens do portfólio: [img/portfolio/ampliadas/](img/portfolio/ampliadas/) e [img/portfolio/reduzidas/](img/portfolio/reduzidas/).

Como executar
- Abra [index.html](index.html) em um navegador moderno (não é necessário servidor).

Onde editar
- Conteúdo/estrutura: [index.html](index.html).
- Estilos: [css/estilo.css](css/estilo.css) e arquivos do Bootstrap em [frameworks/bootstrap/css/bootstrap.css](frameworks/bootstrap/css/bootstrap.css).
- Scripts: [js/scripts.js](js/scripts.js) e integrações em [frameworks/jquery/jquery-3.1.1.js](frameworks/jquery/jquery-3.1.1.js).

Observações
- Recursos externos (Google Fonts, jquery-easing) são referenciados em [index.html](index.html).
- Para produção, recomendo minificar CSS/JS e servir imagens otimizadas nas pastas [img/](img/).﻿
